# Bhuvan Teja Ponakala — Data × AI Portfolio

Static, responsive portfolio with project browsing, a 27-record certificate archive using the original local certificate images, verification links where supplied, and a dedicated printable resume page.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173` and use **Resume** to open `resume.html`. The resume page includes **Print / Save as PDF**.

## Contents

- `index.html`, `styles.css`, `design-overrides.css`, `script.js` — portfolio and interactions
- `resume.html` — readable, printable resume
- `assets/certificates/` — original supplied certificate images
- `RTK.md` — design and review workflow references for future updates
