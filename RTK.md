# Portfolio design workflow

For future portfolio and frontend redesign work, consult these references before implementation and apply the parts that fit the brief:

- Taste Skill: https://github.com/Leonxlnx/taste-skill (install reference: `npx skills add Leonxlnx/taste-skill`)
- Vercel Web Interface Guidelines: https://vercel.com/design/guidelines
- Vercel Web Design Guidelines skill: https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines
- Design system examples: https://github.com/voltagent/awesome-design-md
- Screenshot-to-code workflow: https://github.com/abi/screenshot-to-code
- Browser review reference: https://github.com/microsoft/playwright-cli

## Workflow

1. Inspect project and content sources. Preserve verified biography, project, social, credential, and résumé details; do not invent achievements or URLs.
2. Study all supplied screenshots and map their visual structure before coding. Build a distinctive responsive system, not a literal copy of another site's code or signature effect.
3. Keep certificate assets local, use full-image framing for scans, crop only browser chrome or irrelevant margins, and attach the exact supplied verification link to each record.
4. Make navigation, menus, project browsing, credential previews, and resume viewing keyboard-accessible and mobile-usable. Respect reduced motion and visible focus.
5. Run the site locally and inspect desktop and mobile layouts, project and certificate interactions, image loading, and the resume print view before publishing.
